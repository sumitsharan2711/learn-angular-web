# Erudite Angular Mastery — Course Roadmap

One project: `erudite-angular`. Each `NEXT` delivery adds the next chapter to this workspace.

Every chapter gets a folder under `src/app/modules/`, with one main component trio (`.ts`, `.html`, `.scss`). Examples stay together in the chapter component for learning; shared components and services will be introduced when the application genuinely needs them.

## Module 01 — Foundations and Setup
1. Installation, workspace anatomy, bootstrap and first component
2. Components, metadata, selectors and reuse
3. Templates, interpolation, property binding and event binding
4. Built-in control flow and repeated UI
5. Styling, SCSS and responsive layout

## Module 02 — UI Building Blocks
6. Attribute, class and style binding
7. Directives and reusable behavior
8. Pipes and custom pipes
9. Component communication
10. Component lifecycle and change timing

## Module 03 — Services and Navigation
11. Services and dependency injection
12. Routing, child routes, parameters and query parameters
13. Route guards and authorization
14. Lazy routes, resolvers and navigation UX

## Module 04 — Forms
15. Reactive Forms fundamentals
16. Validation, async validation and cross-field rules
17. Advanced forms and ControlValueAccessor
18. Dynamic and metadata-driven forms

## Module 05 — HTTP and State
19. HttpClient and REST API integration
20. Interceptors, errors, retries and cancellation
21. RxJS fundamentals and practical operators
22. Signals and derived state
23. State-management architecture

## Module 06 — Production Erudite
24. Authentication and authorization UI
25. Angular Material/CDK and design system
26. Tables, paging, sorting, filtering and search
27. File upload/download and reporting
28. Testing components, services, routes and forms
29. Performance, accessibility and security
30. Enterprise feature architecture

## Module 07 — Delivery and Integration
31. Angular + Spring Boot integration
32. Environment configuration and deployment
33. CI/CD pipeline and production checklist
34. Capstone: complete Erudite web application

Each chapter starts with relevant setup, plain-language explanations, analogies, at least three different scenarios, visual flow diagrams, exercises, and a NEXT prompt.
